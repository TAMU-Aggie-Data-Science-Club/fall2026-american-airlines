# Deliverable 4 Model Selection Design

## Goal

Add a new Deliverable 4 to `DELIVERABLES.md` for the week after Deliverable 3. Teams will
build on the real American Airlines data, EDA, and feature set from Deliverable 3 by testing
candidate machine-learning and time-series models and documenting the model they will carry
forward.

## Scope

- Add Deliverable 4, "Model Selection & Baseline Finalization," to the milestone table.
- State that the deliverable uses the real-data feature set produced in Deliverable 3.
- Encourage comparison of XGBoost, Random Forest, LSTM, ARIMA, and other justified candidates.
- Require consistent evaluation, comparison evidence, and a documented final model choice.
- Preserve the Deliverable 3 branch and naming convention:
  `team-##/<name>` → `team-##/main` → `main`.
- Rename the existing tuning and final-findings previews to Deliverables 5 and 6.
- Update the branch-conventions table and references so Deliverables 2–6 use the same team
  branch tree.

## Out of scope

- Implementing models or adding notebooks.
- Changing Deliverable 3's existing instructions.
- Changing the team's branch naming policy.

## Acceptance criteria

- `DELIVERABLES.md` describes Deliverable 4 as a model-testing and finalization milestone.
- The candidate list includes XGBoost, Random Forest, LSTM, and ARIMA while allowing other
  justified models.
- The section explicitly builds on Deliverable 3 and uses its team branch/folder conventions.
- Existing later milestones are consistently renumbered to 5 and 6.
